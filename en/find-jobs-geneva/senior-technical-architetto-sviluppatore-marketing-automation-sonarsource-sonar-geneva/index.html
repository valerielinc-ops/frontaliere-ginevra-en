Who is Sonar?

Sonar enables organizations to ship agentic code with confidence. Code creation is abundant, but confidence is scarce. Our core platform, SonarQube, verifies over 750 billion lines of code every day, delivering agentic verification and governance for all code. Trusted by more than 7 million developers and 75% of the Fortune 100, including teams at Nvidia, ServiceNow, Booking.com , Goldman Sachs, AstraZeneca, and Ford Motor Company, Sonar enables organizations to reduce outages, improve security, and lower the cost and risk of agentic software development.

Founded in Geneva and now headquartered in Austin, Texas, Sonar has a global team working across offices and hubs, including Silicon Valley, London, Bochum, Barcelona, Singapore, Tokyo, and the Washington, D.C. area. At Sonar, we’re enabling enterprises to build agentic software factories that can move quickly while maintaining the control, consistency and evidence required to ship with confidence.

Position Description

We are seeking a deeply technical Marketing Technology Architect / Developer to lead the data architecture, custom code development, system integrations, and infrastructure scalability of our marketing engine.

Our day-to-day stack currently relies on Salesforce Marketing Cloud (SFMC) as our primary engine, and we are actively considering next-generation architecture like Marketing Cloud Next. However, for us, specific tool proficiency takes a backseat to a genuine passion for marketing technology, AI-driven marketing innovations, robust data architecture, and technical problem-solving.

We value your ability to analyze complex data models, integrate APIs, write clean code, and optimize high-throughput automation pipelines over specific certifications. If you are a platform-agnostic technologist passionate about marketing tech stack mechanics and AI marketing tools, this role provides the scope and autonomy to build world-class system infrastructure.

What you will do Data Architecture & Engineering • Operations Enablement: Prepare, clean, structure, and model marketing data for Marketing Operations teams to run campaigns, segment audiences, and manage daily operations friction-free. • Data Modeling: Build and optimize scalable relational database structures, data extensions, custom models, and subscriber key lifecycles for operational needs. • ETL & Data Pipelines: Partner with the Data Team to create automated SQL queries and ETL pipelines ingesting and transforming data warehouse datasets (e.g., Snowflake, BigQuery) into production-ready data extensions. • Governance & Hygiene: Maintain data hygiene, identity resolution, deduplication, and real-time ecosystem syncs to ensure efficiency.

Technical Customization & Custom Development • Write maintainable custom platform code (e.g., AMPscript, SSJS, WSProxy) for personalization engines. • Develop dynamic rendering logic, interactive web forms, and secure landing pages. • Troubleshoot automation failures, script exceptions, and data bottlenecks.

API & Ecosystem Integrations • Architect and maintain API integrations (REST, SOAP, Webhooks) connecting product apps, mobile backends, and third-party systems to the marketing platform. • Configure native CRM and database connectors for low-latency, real-time bidirectional sync. • Manage rate limits, payload efficiency, OAuth, and retry handlers.

Platform Operations & System Health • Monitor runtimes, script performance, and query execution to ensure 99.9% uptime. • Lead security governance, permissions, business unit structuring, and privacy compliance (GDPR, CCPA, CAN-SPAM). • Partner with DevOps and IT Security on domain authentication and deliverability infrastructure.

Experience and qualifications Core Technical Competencies • Advanced SQL & Database Design: Extensive experience with relational data modeling, complex joins, aggregation, and query tuning. • Integrations & Protocols: Strong knowledge of REST/SOAP APIs, JSON/XML, OAuth 2.0, webhooks, and Postman. • Scripting & Code: Skilled in AMPscript, SSJS, or general languages (JavaScript, Node.js, Python) applied to MarTech. • MarTech & AI Curiosity: Passionate about marketing architecture, event triggers, relational mapping, agentic AI, CDPs, and automated personalization.

Experience

• 3+ years in technical architecture, administration, or development in Salesforce Marketing Cloud (SFMC) (Automation Studio, Journey Builder, Contact Builder, CloudPages, APIs, or Data Cloud/AI frameworks). • Practical understanding of how Predictive, Generative, and Agentic AI transform technical marketing. • Proven track record of evaluating and mastering new marketing platforms and technical tools.

Key Personality Traits • Tech & AI Enthusiast: Actively follows MarTech, CDPs, AI automation, and data engineering trends. • Platform Agnostic: Uses tools and AI models adaptively to solve data and communication challenges. • Problem Solver: Enjoys debugging complex data issues, race conditions, integrations, and AI logic edge cases.
