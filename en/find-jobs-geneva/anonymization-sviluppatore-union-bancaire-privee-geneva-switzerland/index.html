Full description

Mission

  • Design, implement, and operate services and tooling for enterprise-grade data anonymization and protection across production databases.
  • Develop and maintain REST API backends enabling anonymization workflows and integration with upstream/downstream systems.
  • Build automation and operational scripts in PowerShell and Bash to deploy, monitor, and manage DAP services.
  • Contribute to backend services and utilities in Java and/or C# with clean, testable, and secure code.
  • Integrate with and support multiple database engines (MongoDB, MS SQL Server, Oracle), including schema discovery, profiling, and rules application.
  • Collaborate with security, data governance, and application teams to define and enforce data masking/tokenization standards and policies.
  • Implement observability (logging, metrics, tracing) and CI/CD pipelines for reliable delivery and operations.
  • Troubleshoot incidents, perform root-cause analysis, and drive continuous improvements in scalability, reliability, and performance.
  • Document APIs, runbooks, and operational procedures; contribute to knowledge sharing and onboarding materials.

Key Qualifications

  • Strong, practical experience building and operating REST API backends (designing endpoints, versioning, authentication/authorization, performance tuning, resilience).
  • Hands-on programming in at least two of the following: Java, C#; and scripting proficiency in PowerShell and Bash.
  • Solid database fundamentals and hands-on experience with:
  • MongoDB (collections, indexing, aggregation, performance basics)
  • Microsoft SQL Server (T-SQL, schema design, indexing strategies)
  • Oracle Database (PL/SQL fundamentals, performance considerations)
  • Experience integrating backends with databases securely (connection handling, secrets management, least privilege).
  • Familiarity with data anonymization/masking/tokenization concepts and patterns.
  • Good understanding of secure software development practices (Kerberos, OWASP, input validation, secrets handling, TLS, logging without leakage).
  • Comfortable with CI/CD tools and version control; experience with automated testing and code quality practices.

Nice to Have

  • Experience with enterprise data masking/tokenization tools or libraries.
  • Knowledge of data governance and privacy frameworks (GDPR, data minimization, DPIA).
  • Exposure to event-driven architectures, message queues, or ETL/ELT pipelines.
  • Containerization and orchestration (eg Docker/Podman, OpenShift) and infrastructure-as-code (e.g., Ansible).
  • Observability stacks (Prometheus/Grafana, ELK/EFK, OpenTelemetry).
  • Performance profiling and capacity planning for API services and databases.
  • Experience in regulated environments (banking/financial services).

Mindset & Soft Skills

  • Ownership mentality with a bias for clean, pragmatic solutions.
  • Strong problem-solving skills and ability to debug complex, distributed issues.
  • Clear communication and collaboration with cross-functional teams.
  • Attention to detail in security and compliance.

Our Tech Environment

  • Languages: Java, C#
  • Scripting: PowerShell, Bash
  • Databases: MongoDB, MS SQL Server, Oracle
  • APIs: REST-first design, OpenAPI/Swagger, OAuth2/OIDC, Kerberos
  • DevOps: Git-based workflows, CI/CD in Azure Dev Ops, containers, observability

What We Offer

  • Opportunity to shape a bank-wide platform critical to data protection and privacy.
  • Collaborative environment with security, data, and platform engineers.
  • Professional development, certifications, and training support.
  • Competitive compensation and benefits aligned with industry standards.
  • Flexible work practices in a modern engineering environment.
  • Location
  • Swiss Residence : Mandatory
