Full description

  • Mission

We are seeking a skilled and experienced Database Engineer to join our team in Geneva and modernize the bank’s data layer on Sybase ASE and Sybase IQ. The ideal candidate will manage and optimize complex stored procedures, re-engineer UNIX ksh and SQL scripts using modern patterns, and ensure reliable ETL pipelines for operational and transactional banking data.

  • Main responsibilities
  • Review existing data systems and architectures to identify improvement and optimization
  • Design, develop, and maintain complex stored procedures, functions, and packages on Sybase ASE Sybase IQ
  • Optimize database performance: indexing, statistics, partitioning, query plans, parallelism, compression.
  • Analyze existing UNIX ksh and SQL scripts; simplify and rewrite with modern structures, parameterization, error-handling, and logging.
  • Develop & manage on-premises applications build on MS .Net & Angular Framework.
  • Build and support ETL/ELT workflows: data ingestion, validation, transformations, reconciliation, and scheduling (e.g., Control M).
  • Ensure data quality and reliability for daily/weekly/monthly cycles; implement monitoring, and alerts.
  • Collaborate with Finance/Operations teams to translate requirements into robust database and batch solutions.
  • Troubleshoot production incidents; perform root-cause analysis and preventative fixes while meeting the SLAs.

Technical skills

  • Sybase ASE and Sybase IQ (8+ years hands-on)
  • Advanced SQL, stored procedures, performance tuning, query plan analysis.
  • Data modeling for large analytical/operational workloads.
  • UNIX/Linux
  • Strong ksh/bash scripting, file handling, scheduling, permissions etc.
  • Banking data
  • Solid understanding of operational/transactional and financial datasets and KPIs (balances, movements, fees, commissions, net interest margin)
  • .NET Framework/C# exposure, experience applying GitHub Copilot for refactoring, app modernization.
  • Agile delivery with JIRA/Confluence and GitHub
