Role overview

Are you passionate about infrastructure at scale and curious about how bare metal servers are managed across a fleet of 10'000 nodes?

Join CERN's IT Cloud team and help run and evolve the OpenStack-based cloud infrastructure that underpins most CERN and LHC experiment services.

In this role, you will work at the intersection of systems engineering and software development, contributing to the life-cycle management of physical servers (from delivery and burn-in to provisioning and phase-out) using OpenStack Ironic.

Main responsibilities

  • Your responsibilities
  • Run and help evolve CERN IT's OpenStack-based cloud infrastructure.
  • Maintain and develop the bare metal life-cycle management framework built on OpenStack Ironic: integrate new server deliveries, provision nodes to user communities, and maintain tooling for burn-in, stress-testing and phase-out.
  • Contribute to the upstream OpenStack/Ironic code base, leveraging CERN's links with the open-source community.
  • Collaborate on automation and tooling improvements using Python and configuration management systems.
