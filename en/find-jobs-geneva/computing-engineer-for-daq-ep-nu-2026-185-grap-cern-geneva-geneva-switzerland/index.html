Full description

As a Computing Engineer (Project Graduate / QUEST) in the EP-NU group, you will develop and operate Data Acquisition (DAQ) software and online infrastructure for CERN Neutrino Platform experiments and the Deep Underground Neutrino Experiment (DUNE). You will take end-to-end ownership of two core deliverables: a dynamic resource-management and configuration layer for deterministic DUNE-DAQ readout performance, and real-time stream reordering within the Data Handling Library of the Readout and Trigger systems. You will generalise these solutions into reusable components for the CERN Controls, DAQ, and Online (CDO) project and integrate them into the DAQling framework. In parallel, you will support online cluster operations and data-taking runs at the Neutrino Platform.

Your responsibilities

  • HW/SW co-design & dynamic resource management: Design, implement, and benchmark dynamic sizing and resource allocation mechanisms for DUNE-DAQ readout functions to guarantee deterministic processing performance under varying detector data rates.
  • Out-of-order stream handling: Evaluate, develop, and integrate low-latency algorithms within the Data Handling Library of the Readout and Trigger systems to detect, sort, and resolve intra-stream disorder and out-of-order events in high-throughput data streams.
  • Library reusability & integration: Generalise validated readout, buffering, and resource-management modules into reusable components within the CDO project, integrating them into the DAQling framework.
  • Control & configuration interfaces: Develop software interfaces and configuration workflows connecting front-end readout hardware, resource managers, and the DUNE-DAQ Run Control.
  • Automated dataflow & cluster infrastructure: Maintain automated data transfer pipelines to CERN central storage (EOS/CTA) alongside Linux cluster provisioning (Ansible) and system telemetry (Prometheus, Grafana).
  • Online operations & commissioning: Provide hands-on operational support, performance profiling, and troubleshooting during detector integration tests and data-taking runs at the CERN Neutrino Platform.
  • This role includes team supervision responsibilities.

Your profile

  • Demonstrated experience in developing, debugging, and maintaining software applications using modern C++ and Python in a Linux environment.
  • Hands-on experience with real-time data handling, network socket programming, and high-throughput data streaming.
  • Experience in distributed systems administration, Linux kernel tuning, and network and storage configuration (e.g., NVMe RAID arrays and NAS file systems).
  • Exposure to automated deployment tools (e.g., Ansible or Puppet), as well as centralised monitoring and logging systems (e.g., Prometheus, Grafana, and OpenSearch/ELK).
  • Experience with relational databases (e.g., Oracle) and/or managing data movement and file transfers.
  • Experience with hardware-near software development, high-throughput data-plane communication (e.g., Ethernet or custom protocols), or supervisory control interfaces (e.g., WinCC OA).

Skills

  • Strong programming skills in C++ and Python, with a solid understanding of software engineering fundamentals and version control.
  • Good understanding of Linux operating system concepts, including process lifecycle, file systems, and network I/O.
  • Familiarity with multithreaded programming concepts, concurrency concepts, and memory management.
  • A versatile mindset with the adaptability to work across application code, scripting, and system infrastructure.
  • Methodical problem-solving and diagnostic skills to troubleshoot technical issues across software and system boundaries.
  • Strong communication skills in English and the ability to collaborate effectively within an international, multidisciplinary team.f
